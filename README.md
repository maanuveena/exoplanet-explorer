# exoplanet-explorer
Exploring real NASA exoplanet data using python and pandas
Exoplanet Explorer

About the Project

Exoplanet Explorer is a beginner-friendly data analysis project that uses real data from the NASA Exoplanet Archive to explore planets beyond our Solar System.

Features

- Loads and explores exoplanet data using Pandas.
- Analyzes exoplanet discovery methods.
- Visualizes discovery methods using bar charts.
- Explores the relationship between planet radius and orbital period.
- Searches for exoplanets by name.
- Compares exoplanet radius with Earth's radius.

Technologies Used

- Python
- Pandas
- Matplotlib
- Google Colab
- NASA Exoplanet Archive

Data Source

NASA Exoplanet Archive: https://exoplanetarchive.ipac.caltech.edu/

Project Goal

To analyze real exoplanet data, visualize patterns, and develop practical Python data analysis skills.
